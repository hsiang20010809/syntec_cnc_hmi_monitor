# CNC HMI Monitor 專案規劃文檔

## 專案概述

### 專案名稱
CNC Machine Monitor HMI (人機介面)

### 專案目的
開發一個模擬 CNC 控制器的人機介面應用程式，展示以下技能：
- C++ 程式設計能力
- GUI 人機介面開發
- TCP/IP 網路通訊
- 即時數據視覺化
- 軟體架構設計

### 目標職位對應

| 職缺要求 | 專案展示 |
|----------|----------|
| 人機介面/元件開發 | Qt GUI 開發、自定義元件 |
| 應用工具開發 | 完整的監控應用程式 |
| 網路通訊架構研究開發 | TCP Client-Server 架構 |
| 熟悉 C++ | 全專案使用 C++ |
| Linux 環境 | Qt 跨平台，可在 Linux 編譯運行 |

### 通訊協定設計

**數據格式：JSON**

```json
{
    "timestamp": 1706860800000,
    "position": {
        "x": 125.350,
        "y": 67.820,
        "z": -15.000
    },
    "spindle": {
        "rpm": 3000,
        "load": 45.5
    },
    "feed": {
        "rate": 500,
        "override": 100
    },
    "status": {
        "state": "RUNNING",
        "mode": "AUTO",
        "alarm": 0
    }
}
```

**狀態碼定義：**

| 狀態 | 代碼 | 說明 |
|------|------|------|
| IDLE | 0 | 待機中 |
| RUNNING | 1 | 運行中 |
| PAUSED | 2 | 暫停 |
| ERROR | 3 | 錯誤 |
| E-STOP | 4 | 緊急停止 |

## 功能規格

### 核心功能 (Must Have)

#### 1. 機台狀態顯示面板
- 顯示當前機台狀態（運行/待機/錯誤）
- 狀態指示燈（綠/黃/紅）
- 主軸轉速顯示 (RPM)
- 進給速率顯示 (mm/min)

#### 2. 座標顯示
- X, Y, Z 三軸座標即時顯示
- 數值精度至小數點後三位
- 單位顯示 (mm)

#### 3. TCP 網路連線
- 連線/斷線按鈕
- 連線狀態顯示
- 自動重連機制（選配）

#### 4. 即時數據圖表
- 主軸轉速歷史曲線
- 最近 60 秒數據
- 自動滾動更新

### 選配功能 (Nice to Have)

- 警報訊息顯示
- 數據記錄匯出
- 多國語言支援
- 主題切換（深色/淺色）

## 技術選型說明

### 為什麼選擇 Qt？

1. **工業界廣泛使用**
   - 許多 HMI 軟體使用 Qt 開發
   - 新代科技可能也使用類似技術

2. **跨平台支援**
   - 符合職缺要求的 Linux 能力
   - 同一份 code 可在 Windows/Linux 運行

3. **完整的功能模組**
   - Qt Widgets: GUI 元件
   - Qt Network: TCP/UDP 通訊
   - Qt Charts: 數據視覺化

4. **Signal/Slot 機制**
   - 優雅的事件處理
   - 非同步通訊處理

### JSON 數據格式原因

1. 人類可讀，便於除錯
2. 跨平台標準格式
3. Qt 內建 JSON 解析支援
4. 工業通訊常見格式
